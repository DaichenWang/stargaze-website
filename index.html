01 · 行业洞察

数字孪生 2.0
从看见到预见

现有工具已让管理方看见正在发生的事——监控网络、客流热力图与几何孪生提供了全景。但下一步的高价值决策需要回答的是：如果这样做，会怎样？这一类反事实推演，目前主要依靠经验、惯例与临场反应。


星纬定位于交互式决策孪生层，以自然语言驱动反事实推演，让管理方在执行之前看到不同策略可能带来的次生反应、群体非理性行为，以及信息传播对路径的扰动。

1.0
Physical Twin
物理孪生
几何高保真复刻；人作为粒子或动画处理；回答「需要多久疏散」这类问题。
2.0
Cognitive Twin
认知孪生
LLM 赋予 Agent 心智；具备记忆、情绪、社交属性；回答「会不会出现恐慌」这类问题。
2.5
Interactive Decision Twin
交互式决策孪生
Chat-to-Sim 自然语言反事实推演；将策略转化为可执行预案。

3.x
Fully Autonomous Twin
全智能孪生
AGI 闭环完成感知、推理、决策与执行；远期愿景。

03 · 核心技术

ARIA 架构
自主推理-交互智能体

LLM 仅在初始设置和关键事件中介入；Agent 的决策由引擎执行；场景为整个系统提供物理约束。这种分工使推演具备可解释与可复现的工程特性。



护城河在于 ARIA 架构、场景资产、Persona 库与校准参数——这些是行业特有资产，不会随基础模型迭代而贬值。

01
Scene · Substrate
场景层
路网拓扑、建筑边界、人行道、斑马线、容量、设施、时段、天气。来源：OSM 自动拉取 + 高精度地图补充 + 用户自定义。
02
LLM · Orchestrator
LLM 层
将自然语言指令翻译成可执行规则；触发关键事件；生成 Persona 模板；解释推演结果。不参与单步行为决策与时间步进。
03
Agent · Individual
智能体层
状态包括目标、记忆、情绪和社会关系。三个层次：完全智能体 / 半智能体 / 群体跟随者。决策依据：场景约束 + LLM 规则 + 自身状态。
04
Engine · ABM
仿真引擎层
推进时间步进；应用物理约束（速度、碰撞、容量）；防穿墙、防瞬移、防超容量，将大模型常见物理失真排除在外。
04 · 应用场景

在决策流程中
我们扮演的角色

G 端 · 公共安全
上线前的场景
压力测试
节庆、跨年观礼、大型赛事和集会等场景下，把候选方案放入仿真，输出瓶颈位置、最坏疏散时长、扰动下的连锁反应。适用：城运中心、应急管理、文旅、轨交、大型场馆运营方。
交付物
  • 场地推演报告
  • 风险点清单
  • 策略备选方案集
B 端 · 商业运营
户外商业空间
方案选择
潮玩展、户外快闪、市集、商业街区与商圈节庆活动的运营方，在动线、围栏、岗位部署上需要快速决策。仿真比较多套方案，输出覆盖率、停留分布、预计排队与处置损失。
交付物
  • 方案对比报告
  • 运营建议清单
  • 可视化推演视频
